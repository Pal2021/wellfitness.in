# Exercise photographs

The movement photographs in this directory come from the [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) image collection. The project describes its repository as public domain under the Unlicense. `frontend/src/features/exercise/data/exercisePhotoSources.json` records the source image path used for each seeded Wellfitness exercise. Filenames here use the Wellfitness exercise names.

Some Wellfitness names use the closest available movement variation: Bulgarian Split Squat uses Split Squats, and Nordic Curl uses Natural Glute Ham Raise.
